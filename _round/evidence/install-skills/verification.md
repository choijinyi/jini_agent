### 4-3. 종료 코드 — 가설이 틀렸음을 실측으로 확인

스킬 확인을 마지막으로 옮기면 스크립트 종료 코드가 그것에 물려
`setup.ps1:87`(`if ($LASTEXITCODE -ne 0) { throw "설치 실패" }`)이 설치를 실패로 뒤집을 것이라고
**추정했으나, 측정 결과 그렇지 않았다.**

```
tail(if 블록으로 끝남, node exit 1)         -> exit 0
tail(네이티브 명령이 문자 그대로 마지막)     -> exit 0
대조군: 명시적 `exit 3`                      -> exit 3   ← 비0 감지 가능함을 확인
대조군: `throw "boom"`                       -> exit 1
install.sh 꼴(스킬 확인 실패)                -> exit 0
install.sh 꼴(스킬 확인 성공)                -> exit 0
```

대조군이 비0을 정확히 잡아냈으므로 위 0 들은 계측 실패가 아니다.
→ **살아 있는 버그는 없었다.** `install.ps1` 의 `exit 0` 은 버그 수정이 아니라,
이 블록이 파일 맨 끝이라 향후 편집 한 번으로 성질이 조용히 바뀌는 것을 막는 **회귀 고정**이다.
코드 주석과 selftest 주석 모두 이 사실대로 고쳐 적었다(처음 쓴 주석은 틀린 근거를 담고 있었다).

## 6. 재지 못한 것 (고지)

정직하게 남긴다 — 아래는 **검증했다고 말할 수 없다.**

1. **install.sh / install.ps1 전 구간 실행은 하지 않았다.** `npm install` 이 electron 바이너리를
   내려받아 비용이 크다. 대신 ⓐ변경한 블록을 동일 셸 구성으로 분리 실행하고 ⓑ전체 문법을
   파서로 검사했다. 클론→검증 구간의 전 구간 실행은 선행 세션(2.15)이 임시 클론으로 수행한 기록이 있다.
2. **Linux/macOS 실기 실행 없음.** bash 구성은 Git Bash(Windows)에서 확인했다.
4. **사람이 실제로 그 고지를 읽는지**는 측정 대상이 아니다. 마지막에 배치했다는 사실만 고정했다.
